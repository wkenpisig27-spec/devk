## D3DRS by subsystem (native relevance)

### World / scene (RenderStateMgr + SceneRender + MPMap)
  D3DRS_LIGHTING, D3DRS_AMBIENT          -> lwD3D11Mesh CB lighting
  D3DRS_TEXTUREFACTOR                    -> mesh CB tfactor / item tint
  D3DRS_FOGENABLE, FOGCOLOR, FOG*        -> MPMap legacy; DX11 fog via lwD3D11MeshSetVisual
  D3DRS_ZENABLE, ZWRITE, ALPHABLEND      -> pass bundles + per-draw override
  D3DRS_CULLMODE                         -> mesh rasterizer pick
  D3DRS_SRCBLEND, DESTBLEND              -> mesh blend (particles override)

### Character (RenderStateMgr::_rsa_cha + SceneRender)
  Same as world; pass tag lwD3D11MeshSetCharacter -> PSO bundle "character"

### Scene object (RenderStateMgr::_rsa_sceneobj)
  AMBIENT 0xffa0a0a0, LIGHTING TRUE       -> mesh CB; pass tag SetSceneObject

### Transparent (RenderStateMgr::_rsa_transpobj)
  LIGHTING FALSE, alpha blend             -> mesh CB more[1]; pass tag SetTranspObject, depth_read bundle

### VFX (EffectFile, MPParticle*, MPModelEff, I_Effect)
  Full FF block in EffectFile::Begin — mesh OM overrides per effect
  ZWRITEENABLE toggles                    -> must remain cache overrides on top of pass bundle

### UI (UIRender, BitmapFont, GameAppInit loading)
  Z off, alpha test, no lighting          -> primarily lwD3D11Blit; not pass bundles

### Minimap (SMallMap)
  Isolated 2D state stack                 -> separate from world pass bundles

## Pass bundle mapping (Phase 3 implementation)
  character   : depth_write ON, blend SRCALPHA/INVSRCALPHA, cull from cache
  scene_object: same OM as character; stylized CB via scene_object flag (future)
  transparent : depth_read, blend SRCALPHA/INVSRCALPHA; cache overrides for additive/ZWRITE
  terrain     : depth_write ON, blend SRCALPHA/INVSRCALPHA; no stylized cel (look.w)
  default     : full cache translation (untagged draws)
